# Changelog

All notable changes to this extension are documented in this file.

## Unreleased

- Added folding controls for multiline CSS blocks in recognized tagged templates.
- Added a lazily loaded workspace CSS index for custom-property completion, definition,
  references, hover source information, and static CSS mixin completion.
- Added incremental project-index updates for file and workspace-folder lifecycle changes,
  with cancellation and file-count, file-size, and total-size limits.

## 0.1.0 - 2026-08-24

- Added standalone VSIX packaging with bundled CSS language-service dependencies.
- Added JavaScript and JSX syntax highlighting and completion support.
- Added an Extension Development Host launch configuration and an isolated test workspace.
