# vscode-yak

MVP VS Code extension that provides CSS syntax highlighting and IntelliSense for `yak` tagged templates.

## Package

```sh
yarn install
yarn package
```

The VSIX package is created at `build/vscode-yak-<version>.vsix`.

## Use

Drag `build/vscode-yak-<version>.vsix` into the VS Code Extensions view to install it.
